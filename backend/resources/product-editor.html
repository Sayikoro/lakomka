Как пользоваться редактором — 6 шагов
  1. В админке: Товары → Экспорт ZIP — скачайте архив (внутри products.csv, картинки, видео и эта страница).
  2. Перетащите ZIP целиком на эту страницу (распаковывать не обязательно) — либо только products.csv.
  3. Отредактируйте товары: правьте прямо в таблице или откройте карточку кнопкой ✎. Строку можно продублировать (⧉) или удалить (✕). Новые строки без ID создадутся как новые товары.
  4. Медиа: превью видно прямо в таблице (видео проигрывается без кнопок). Добавляйте файлы перетаскиванием в зоны «Картинки» / «Видео» в карточке товара (jpg/png/webp/gif · mp4/webm/mov) — при «Сохранить ZIP» они войдут в архив. Убрать медиа — ✕ на плитке (на сайте оно удалится при импорте).
  5. Нажмите «Сохранить ZIP» — скачается готовый архив с вашим products.csv и всеми медиа. Либо «Скачать CSV» и добавьте его в исходный архив вручную (замените products.csv).
  6. В админке: Товары → Импорт ZIP с сохранённым архивом. Товары с существующим ID/slug обновятся, новые — создадутся.

Важно: импорт не удаляет товары, которых нет в CSV — удалённая из таблицы строка просто не будет затронута на сайте. Медиа товара при импорте пересоздаются: имя файла, у которого нет файла в архиве (красные ⚠ в карточке), приведёт к удалению этого медиа у товара на сайте. Файлы, добавленные drag&drop, живут, пока открыта страница — не забудьте «Сохранить ZIP». Колонка «Показ» для конфет (тип recipe) при импорте всегда станет 0 — конфеты не показываются в каталоге напрямую. УПАКОВКА — одно из: cardboard, tin, textile, tube, pouch (или пусто).
