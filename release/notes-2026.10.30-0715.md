Лакомка v2026.10.30-0715 — видео из галереи, дампы БД, живой hero

1. Привязка файлов из галереи без «Допустимы только файлы из /uploads/»:
   файл добавляется к товару из любой папки с любым именем (юникод,
   пробелы, скобки). Защита от выхода за пределы /uploads сохранена
   (realpath-проверка).

2. Медиа-галерея, вкладка «Видео»:
   - ищет все видео (mp4/webm/mov/m4v) сразу по всем папкам /uploads,
     новее сверху, с поиском и счётчиком;
   - поле «папка видео» + кнопка «Запомнить и искать» — можно закрепить
     свою папку (настройка gallery_video_folder), галерея будет открываться
     с ней;
   - несуществующая папка больше не даёт ошибку — просто пустой список;
   - загрузка в режиме видео летит в выбранную папку.

3. Миграции базы данных с автоматическим дампом:
   - перед каждым изменением структуры БД автоматически снимается копия
     базы в backend/storage/backups (хранятся последние 10);
   - копии видны и скачиваются в проводнике: раздел «Дампы базы данных»;
   - механизм версионированных миграций (backend/migrations/*.sql,
     таблица schema_migrations) — базу можно спокойно дорабатывать;
   - первая миграция: индекс по product_images.url (ускоряет привязку
     файлов и удаление медиа).

4. Hero-картинка стала «живой»: загруженное в админке изображение (и слайды)
   появляется на сайте после обновления главной страницы (F5) — без
   пересборки сайта. Для фото iPhone (HEIC) — понятное сообщение
   («сохраните как JPG»); AVIF теперь принимается.

Обновление ставится кнопкой «Проверить обновления (ГИТ)» → «Скачать и
установить» (медиа и база данных не затрагиваются). После установки
обновите админку (Ctrl+F5).
