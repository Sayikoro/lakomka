Лакомка v2026.10.30-1134 — импорт находит файлы на сервере

ГЛАВНОЕ
1. При импорте товаров файл из CSV, которого НЕТ в ZIP, теперь сначала
   ищется на сервере — и только если его нет нигде, появляется пометка
   «не найдено».
   - Видео ищутся в первую очередь в вашей папке /uploads/video,
     затем во всех остальных папках /uploads.
   - Картинки — по всем папкам /uploads.
   - Найденный файл привязывается к товару КАК ЕСТЬ, без дублирования
     (копий не создаётся, место не расходуется).
2. «Лёгкий» архив (только CSV, без папок images/ videos/) больше не
   стирает медиа: файлы, уже лежащие в папке товара, перепривязываются
   на месте и защищаются от удаления.
3. Правила поиска (безопасность и точность):
   - Канонические имена (0.jpg, video-0.mp4) ищутся только в папке
     СВОЕГО товара — чужие файлы с тем же именем не подмешиваются.
   - Оригинальные имена (клип.mp4, фото.jpg) ищутся по всем папкам.
   - Путь вне /uploads (../) подставить нельзя; привязываются только
     медиа-файлы (jpg/png/webp/gif — картинки, mp4/webm/mov — видео).
4. В отчёте импорта — зелёная строка «Найдено на сервере: видео — N,
   картинок — M»; формулировка «не найдено» стала честной: «ни в ZIP,
   ни на сервере».

УСТАНОВКА
- Штатно: /update → «Проверить обновления (ГИТ)» → «Скачать и установить».
  Медиа и база данных не затрагиваются.

ПРИМЕЧАНИЯ
- Все исправления предыдущих релизов (кнопка «Сжать», живая витрина,
  галерея-карусель, видео без 503, снегопад, дампы БД) сохранены.
