# Лакомка — обновление v2026.11.03-0212

## Бот-детект v2: ИИ-агенты больше не проходят за людей

В прошлой версии аналитики автоматизированные посетители распознавались по User-Agent и по флуду страниц. Но ИИ-агенты (DeepSeek и подобные) ходят по сайтам с обычным Chrome-UA и неспешно — аналитика принимала их за людей. Теперь детект работает по трём независимым контурам:

- **Отпечаток браузера**: витрина сообщает обезличенные признаки — флаг автоматизации `navigator.webdriver` (честно включается у Selenium/Puppeteer/Playwright), наличие объекта `window.chrome` (сверяется с настоящим User-Agent — так ловятся переименованные headless-клиенты), число плагинов и языков, тач-устройство, часовой пояс.
- **Человеческий ввод**: считаются движения мыши, касания и нажатия клавиш. Живой человек за любую сессию почти всегда двигает мышью или касается экрана; скрипт-обходчик «молчит». Тач-устройства без ввода не штрафуются (человек может просто читать), быстрый отказ со страницы — слабый сигнал.
- **Серверные заголовки**: отсутствие `Accept-Language` (браузеры человека отправляют его всегда) добавляет к подозрительности.

Каждый признак весит свой балл; **итог ≥ 60 → бот** (причина вида «fp: webdriver»), **30…59 → жёлтый бейдж «Подозрение»** в списке посетителей (сводка показывает, сколько таких за период). Ни один одиночный «мягкий» признак человека ботом не делает — ложных срабатываний на живых посетителей нет. В карточке визита теперь виден отпечаток: webdriver, Chrome-объект, плагины, языки, тач, мышь, касания, клавиатура, Accept-Language.

- В User-Agent-список добавлены ИИ-краулеры: DeepSeek, Perplexity, ChatGPT-User, Meta-ExternalAgent, Amazonbot, Diffbot, YouBot.
- Старые добрые проверки на месте: боты по UA (50+ сигнатур), флуд ≥25 страниц за 2 минуты → «бот (поведение)», блокировка IP в один клик, лимиты (каталог 120/мин, заказы 5/мин и 30/час), IP хранится только как необратимый хеш.

## Техническое

- Починен падение files-роутов (500) на PHP 8.4: явный nullable-тип параметра в контроллере файлов.
- Миграция БД применяется автоматически при первом запросе (с автоматическим дампом базы перед ней).

## Прочее

- Просмотр аналитики доступен всем ролям админки; блокировка IP — редактору и супер-админу; очистка — только супер-админу.

*После применения: обновление ставится штатно (Настройки → «Обновление» или страница /update). Проверить: попросите ИИ-ассистента зайти на сайт — в «Аналитике» его визит должен прийти ботом с пометкой «(отпечаток)», а в карточке визита будет видно, какой признак его выдал. Обычные посетители по-прежнему «Человек»; сомнительные — жёлтое «Подозрение» с баллом.*
