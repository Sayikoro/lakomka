# v2026.11.04-0440 — видео в карточках и «моргание» картинок (Task 138)

Исправления витрины по наблюдениям владельца: самопроизвольная загрузка видео в каталоге, видео на первом подарке в Safari и повторное «моргание» всех картинок после загрузки страницы.

## Видео в карточках каталога
- **Выключенная галочка теперь реально выключает.** Раньше сборка запекала включённые видео из dev-настроек, и до ответа сайта карточки рендерили видеослайды — браузер начинал качать видео (у 165 из 271 товаров они есть), а в Safari видео показывалось кадром на первом подарке. Теперь видео в карточках включается только явной галочкой «Показывать видео в карточках каталога» (сейчас выключена).
- **Если галочку включить** — видео больше не качается «пачкой»: файл подгружается только когда пользователь листает до видео-слайда, а до того на месте слайда видно фото товара (постер) — в том числе в Safari, без чёрного квадрата.

## «Моргание» картинок
- Слайды карточек и миниатюры галереи товара больше не перемонтируются при обновлении живых данных каталога: раньше идентификаторы медиа в базе сборки и на сервере расходились, и после подгрузки свежих данных все картинки гасли в скелетон и проявлялись заново. Теперь ключом служит адрес файла — картинки с неизменившимся адресом остаются на экране.

## Техническое
- `card_video_enabled`: дефолт false, из API принимается только явный boolean true; dev-БД сборки приведена к выключенному состоянию.
- Стабильные ключи слайдов `type+url` (ProductCardNew, ProductGallery), `SlideVideo`: `preload="none"` + `poster`.
- Тесты: новые task138-tests (15/15) и task138-e2e (стенд с искусственным дрейфом данных: 0 видео-элементов и 0 mp4-запросов при выключенных видео, DOM-узел картинки неизменен через 3,5 с — моргания нет; при включённых — preload=none+poster). Регресс 15 батарей (115–136) и e2e админки/BootSplash — зелёные.
