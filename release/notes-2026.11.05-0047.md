# Лакомка — обновление v2026.11.05-0047

## Счётчик «До Нового года» — новое место и фирменный синий

- **Блок переехал ниже**: теперь он стоит после плиток СКИДКА / ДОСТАВКА / ОПЛАТА и перед категориями.
- **Фирменный синий цвет**: блок окрашен в тот самый синий, что используется по всему сайту, с плавным переходом оттенков.
- **Плавная анимация появления**: при прокрутке страницы карточки отсчёта поднимаются одна за другой, провод гирлянды «прорастает» из центра, огоньки загораются по очереди и продолжают мерцать. При наведении карточки плавно приподнимаются.
- Всё остальное без изменений: отсчёт тикает каждую секунду, галочка в настройках включает/выключает блок, тексты редактируются в админке.

## Как обновить

Админка → /update → «Проверить обновления (ГИТ)» → применить.
