# Релиз v2026.11.01-0754 — Task 116: починка битых картинок + «Неиспользуемые файлы»

## Симптом, который вы прислали

После массовой оптимизации на сайте посыпались 404 на картинки вида
`uploads/products/<товар>/0.webp`. Разбор показал цепочку: страницы сайта
запечены со ссылками на `.webp`, а самих файлов на сервере не оказалось —
по разным причинам (товары, добавленные после последнего медиа-синка,
молчаливые неудачи записи на диске, ручные удаления «одинаковых» имён).

Кстати, про «оптимизатор разные файлы подписывал одним и тем же названием»:
это НЕ ошибка — у каждого товара своя папка, и в каждой своя `0.webp`.
Одинаковые имена в разных папках — норма, ничего переименовывать не нужно
(теперь подсказка об этом есть прямо в окне оптимизатора).

## Что сделано

### 1. Картинки на сайте самолечатся (витрина)
- Все картинки товаров/хиро рендерятся через SmartImg: если файл по ссылке
  отдал 404, компонент сам пробует ту же папку/то же имя с другим
  расширением (webp → jpg → jpeg → png), пока что-то не откроется.
- Работает даже если ошибка случилась до подключения React (ошибка «из
  кеша») — ровно тот случай, который раньше оставлял дырку на странице.
- Покупатель картинку видит, даже если ссылки в базе и файлы разошлись.

### 2. Кнопка «🔗 Починить ссылки на картинки» (админка → Товары)
- Одна кнопка рядом с массовой оптимизацией. Сервер сверяет КАЖДУЮ ссылку
  на картинки (товары + hero-слайды + снежинка) с файлами на диске:
  - файла нет, но рядом лежит исходник jpg/png → **доконвертирует WebP на
    месте** (то, что оптимизатор не доделал — например, из-за нехватки
    места в момент прогона);
  - доконвертить нечем → переписывает ссылку на существующий файл той же
    папки;
  - файла нет ни в одном формате → честный список «потерянных» (такие
    картинки нужно перезалить в товаре).
- Ничего не удаляет; отчёт показывает каждую правку (было → стало).

### 3. «Неиспользуемые файлы» в файловом менеджере — надёжнее
- Кнопка уже была (Файлы → «Неиспользуемые») — теперь она безопаснее:
  - **обложки каталогов (папка pdfs) больше не считаются мусором** — раньше
    их можно было случайно удалить навсегда;
  - файлы витринных настроек (hero-слайды, снежинка) защищены от списка;
  - удаление теперь **в корзину** (восстановимо 30 дней), а не навсегда.

### 4. Оптимизатор больше не путает одинаковые имена
- «Картинки → WebP»: если файла по точному пути уже нет — честный 404 и
  подсказка «обновите список» (в отчёте — как пропуск, не ошибка). Раньше
  сервер искал ЛЮБОЙ файл с тем же именем по всему дереву и мог
  сконвертировать чужую картинку из чужой папки товара.
- Переписывание ссылок в базе теперь только после того, как файл реально
  записан на диск (квота/права больше не дают «ссылку в никуда»).
- Тот же контроль неоднозначных имён добавлен и в видео-«Сжать».
