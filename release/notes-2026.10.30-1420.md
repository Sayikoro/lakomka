Лакомка v2026.10.30-1420 — подтверждение удаления с «Не показывать больше»

ГЛАВНОЕ
1. В файловом менеджере (/admin/files) при удалении файла или папки
   вместо системного окна браузера теперь собственная плашка
   «Удалить?» в стиле админки: что удаляется, «Действие необратимо»,
   кнопки «Отмена / Удалить» (красная).
2. В плашке есть галочка «Не показывать больше»: отметьте её один раз —
   и следующие удаления проходят сразу, без вопроса. Настройка хранится
   в браузере администратора (localStorage), поэтому у каждого
   администратора на своём компьютере своя, работает и между вкладками.
3. Вернуть подтверждение легко: кнопка-щит на панели инструментов
   проводника. Когда подтверждение выключено, она подсвечена жёлтым;
   клик возвращает вопрос и показывает уведомление (включение/выключение
   тоже сопровождается уведомлением — невозможно включить случайно).
4. Безопасность на месте: «Отмена» и клик по фону ничего не удаляют,
   текст честно предупреждает про необратимость; для папок отдельно
   указано «и всё её содержимое».

УСТАНОВКА
- Штатно: /update → «Проверить обновления (ГИТ)» → «Скачать и установить».
- Либо вручную: updates/lakomka-update-2026.10.30-1420.zip распаковать
  в корень сайта с заменой файлов (база и медиа не затрагиваются).

ПРОВЕРЕНО
- Вживую в браузере: плашка появляется, «Отмена» ничего не трогает,
  галочка отключает вопрос (следующие удаления идут сразу),
  кнопка-щит возвращает подтверждение; localStorage сверен.
- tsc 0, ESLint на файле чисто (подтверждение читается через
  useSyncExternalStore — без setState в эффектах, SSR-безопасно).
- Регресс: серверные тесты 84/85/86/87 не затронуты (правка только
  клиентского компонента), серверное API удаления без изменений.
