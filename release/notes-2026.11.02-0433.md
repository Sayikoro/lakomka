# Лакомка — обновление v2026.11.02-0433

## Товары: пагинация

- **Исправлено бесконечное обновление списка** — страница товаров постоянно перезапрашивала данные (мигал индикатор «обновляем…»). Причина техническая: объект с фасетами фильтров попадал в зависимости эффекта загрузки и перезаписывался сам собой. Теперь список грузится один раз и перечитывается только при смене фильтров/страницы.
- **По 20 товаров на страницу** (было 50). В списке «На странице» по-прежнему можно выбрать 50/100/200.
- **Список сам обновляется после импорта ZIP** («Импорт товаров») — новые товары видны сразу, без перезагрузки страницы. Новые товары при создании всегда первые (сортировка по умолчанию «сначала новые»).

## Корзина файлов

- **Восстановление починено и укреплено**: файл возвращается даже если имя внутри позиции не совпало с меткой (та самая ошибка «не найдено»), при неудачном переименовании используется копирование, ошибки стали понятными и называют позицию и путь.
- **Каждая позиция показывает подарок**: название подарка с обложкой (файл опознаётся по своей папке `products/<папка>`), ниже — имя файла и прежний путь. Больше не нужно угадывать, какой из безликих `video-0.mov` чей.
- **Скачивание из корзины** (кнопка «⬇»): файл сохраняется на диск **именем подарка** — удобно подставить исправный файл и загрузить заново.
- **Позиции без метки (meta.json)** теперь видны с бейджем «без meta» — их можно скачать или стереть (восстановить нельзя, путь неизвестен). Новые удаления пишут метку до переноса, таких позиций больше не появится.
- **Кнопка «Очистить корзину»** в шапке диалога — стирает всё одним нажатием с обычным подтверждением. Автоочистка старше 30 дней сохранена.

## Мелочи

- Точечные файлы (.DS_Store) больше не оставляют «зомби-папки» в корзине при удалении.

## Обновление

Админка → `/update` → «Проверить обновления (ГИТ)» → применить. Статический кэш обновится автоматически.
