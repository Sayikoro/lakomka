Лакомка v2026.10.31-0206 — контекстное меню в файлов менеджере (правый клик)

ГЛАВНОЕ
1. Админка, «Файлы» (/admin/files): ПОЛНОЦЕННОЕ КОНТЕКСТНОЕ МЕНЮ по
   правому клику мыши — на файлах, папках и пустом месте списка.
   Долгое время действия были только кнопками в строке, теперь всё
   как в проводнике:
   - на ПАПКЕ: «Открыть», «Свойства», а для удаляемых разделов ещё
     «Переименовать» и «Удалить» (красным, через разделитель);
   - на ФАЙЛЕ: «Открыть в новой вкладке» (если у файла есть публичная
     ссылка), «Скачать», «Копировать ссылку», «Свойства», плюс
     «Переименовать» и «Удалить» для удаляемых разделов;
   - на ПУСТОМ МЕСТЕ: «Обновить», «Загрузить файлы сюда», «Создать
     папку», «Свойства папки» (в корне — только «Обновить»).
2. Новое окно «Свойства» (как в проводнике Windows): тип, полное
   расположение, размер (у папок — суммарный размер и число файлов),
   дата изменения, публичная ссылка с кнопкой «Копировать», и строка
   о том, разрешены ли переименование/удаление («только просмотр» для
   медиа). Для файла в свойствах есть кнопка «Скачать», для папки —
   «Открыть». Окно открывается и из меню, и кнопкой «⋯» в строке.
3. «Копировать ссылку» кладёт в буфер публичный адрес файла
   (/uploads/...), а для файлов без него — ссылку на скачивание через
   админку. Плашка-подтверждение «Ссылка на „...“ скопирована»
   появляется сверху; при недоступном clipboard API (не-HTTPS) есть
   запасной способ копирования.
4. Сенсорные экраны и мобильные: меню вызывается ДОЛГИМ ТАПОМ
   (0,55 с) на строке или плитке, а также кнопкой «⋯» в каждой строке
   («Ещё действия»); в виде «значки» кнопка «⋯» появилась и у
   защищённых от изменений файлов (раньше у медиа не было вообще
   никаких действий на плитке). Случайный клик сразу после долгого
   тапа подавляется — не открывает файл/папку.
5. Меню умное: пункты, недоступные в данный момент, гаснут (например,
   «Переименовать», пока файл занят перекодированием/удалением);
   меню не вылезает за края окна (прижимается к границе), закрывается
   кликом мимо, по Esc, при скролле, изменении размера окна и потере
   фокуса вкладки. Заголовок меню показывает тип и имя файла.
