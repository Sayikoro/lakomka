# Релиз 2026.11.24-0330 (Task 159) — «Тубы» в каталоге: честный фильтр, плитка в списке фильтров

## Что было не так

- Клик по плитке «Тубы» на главной вёл на `/catalog/tuby`, но вместо туб
  показывался **весь каталог**.
- В фильтрах каталога плитки «Тубы» **не было вовсе**.

## Причина (двойная)

1. Выбранная категория резолвилась из списка категорий «с товарами»:
   у «Туб» в базе сейчас 0 товаров → категория не находилась (`undefined`)
   → фильтр молча не применялся → отображались все товары. Плюс —
   запечённый SEO-лендинг пустой категории содержал весь каталог.
2. Плитки фильтров рисовали только категории, у которых уже есть товары —
   у пустой категории плитки не было, фильтра «как такового» тоже.

## Что сделано

- **Фильтр категории работает всегда:** выбранная категория ищется в
  полном справочнике категорий. Пустая категория теперь честно фильтрует —
  и показывает понятное пустое состояние, а не весь каталог.
- **Пустое состояние называет категорию:** «В категории «Тубы» пока нет
  подарков. Посмотрите другие разделы каталога.» Текст редактируется в
  админке («Настройки → Текст на страницах → Каталог», ключ
  `catalog_category_empty`, `{name}` — название категории).
- **Плитка «Тубы» появилась в фильтрах каталога** (рисуются все категории
  из справочника). Клик — честный пустой результат + кнопка «Сбросить
  фильтры»; адрес синхронизируется `?category=tuby`.
- Старые ссылки с главной (`?category=…`) и SEO-лендинги категорий
  (`/catalog/<slug>`) работают как раньше — непустые категории
  фильтруются по-прежнему.

## Как наполнить «Тубы» товарами

- В админке: «Товары» → карточка товара → поле **«Категория»** → выбрать
  **«Тубы»** → сохранить.
- Товар появится в разделе без пересборки сайта: лендинг `/catalog/tuby`
  и плитка фильтра подтягивают каталог живым API (проверено e2e «живого
  пути»: товар, назначенный категории в базе, появился на лендинге сразу
  после правки).
