# Лакомка — обновление v2026.11.04-0608 (Task 139)

Витрина: «Похожие подарки» и «Недавно смотрели», админка: конверсия в аналитике, ловушка для ботов, аудит безопасности.

## Витрина

- **Похожие подарки** в карточке товара: 4 подарка из той же категории, затем ближайшие по цене. Данные обновляются с сервера без пересборки. Карточки — только картинки, без видео.
- **Недавно смотрели** в каталоге: колонка под фильтрами на компьютере; на телефоне и планшете — в самом низу страницы. История хранится только в вашем браузере (до 12 последних подарков), регистрация не нужна. Заголовки блоков редактируются в «Текст на страницах».

## Админка

- **Аналитика → Популярные подарки**: новая колонка **«Конверсия»** — какой процент просмотров закончился «в корзину» (≥10% подсвечивается зелёным).
- **Защита от ботов-заказчиков**: в форме заказа установлена невидимая ловушка — скрипты и автозаполнители, заполняющие всё подряд, получают отказ, а их визиты фиксируются в разделе «Боты» аналитики (обычные покупатели ничего не замечают).
- **Детектор ИИ-агентов усилен**: распознаются программы, которые «кликают» по сайту без движений мыши, и всплески десятков страниц за секунды.
- **Аудит безопасности**: проверены авторизация всех админ-роутов, SQL-запросы, загрузка файлов, XSS; на API добавлены заголовки `X-Content-Type-Options: nosniff` и `X-Frame-Options: DENY`.
