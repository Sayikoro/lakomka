Обновление «Лакомки» 2026.11.02-0344 — отчёт по видео с подарками и ZIP-замена битых файлов.

## Что нового

**Отчёт сжатия теперь показывает подарки, а не безликие файлы**
- В списке массовой оптимизации у каждого файла — название подарка и его обложка (миниатюра; если обложки нет — заглушка 🎁).
- То же в отчёте после прогона: подарок → файл → результат.
- CSV-отчёт получил колонку «товар».

**Диагностика битых видео (файлов-«дыр»)**
- Видео, состоящее из нулей (данные не записались при загрузке/переносе), теперь распознаётся мгновенно и БЕЗ ffmpeg: «видео повреждено: файл состоит из нулей — замените файл исправным». Раньше такой файл гонял 11 попыток ffmpeg и падал с техношумом «Invalid data found when processing input».
- Битые файлы помечаются красным бейджем «повреждено (нули)» / «повреждено» прямо в списке видео.
- Состояние видео видно и в медиа-галерее (тот же API).

**ZIP-отчёт в архитектуре импорта — замена битых файлов через HTML**
- Кнопка «⬇ ZIP для замены файлов (импорт)» в отчёте собирает архив с products.csv (тот же формат, что у экспорта товаров) + папками images/ и videos/ по ВСЕМ медиа затронутых товаров.
- Замените битые файлы в videos/ на исправные (имена сохраните) и загрузите архив через «Импорт товаров» — медиа этих товаров перестроится целиком, как при обычном импорте.
- В интерфейсе после сборки показывается точный список «что заменить» (товар → имя файла в архиве).

**Неиспользуемые видео**
- Видео, не подключённые ни к одному товару, теперь помечаются «не подключена к товарам» (раньше так показывались только картинки).
- Рядом кнопка «в корзину» — файл переедет в «Файлы → Корзина» (восстановимо 30 дней), а не исчезнет.

## Мелочи
- Список видео отдаёт товар по привязке из базы, а для отвязанных — по папке products/<папка> (включая исторические <slug>-<id>).
- Списки картинок тоже получили название товара и обложку.

## Исправлено
- Нулевые/обрезанные видео больше не запускают каскад перекодирования — экономия CPU shared-хостинга и честная причина вместо «Invalid data found».

Ставится кнопкой «Проверить обновления (ГИТ)» на странице /update или в админке (Настройки → Обновление). Медиа и база данных не затрагиваются.
