# Релиз 2026.11.01-0304 (Task 111) — загрузка до 1 ГБ + живые описания PDF

## Чанковая загрузка: потолок поднят до 1 ГБ

- **Импорт-архивы 600–700 МБ больше не отклоняются.** Прежний лимит был
  500 МБ (1000 чанков × 512 КБ) — ваш zip просто не доходил до импорта.
- Клиент и сервер согласованно подняты до **2000 чанков × 512 КБ = 1 ГБ**.
  Размер чанка сознательно не рос: POST ~700 КБ проходит и дефолтный nginx
  (client_max_body_size 1 МБ), и лимиты PHP shared-хостинга — «медленно,
  но всё загрузится».
- Под новое окно подтянут лимит видео в файловом менеджере: 512 МБ → **1 ГБ**
  (картинки 32 МБ и PDF 64 МБ остались как были).
- **Защита от переполнения диска:** перед склейкой чанков сервер проверяет
  свободное место (нужно ~размер файла × 1,1 на чанки + результат); не
  хватает — честная ошибка с числами, а не молчаливый обрыв.
- Работает везде, где чанк-загрузчик уже использовался: импорт товаров ZIP,
  файловый менеджер, вкладка «Обновление».

## Описание PDF на странице «Скачать каталоги» — живое

- **Причина:** страница /catalogs собирается статикой, и описание из админки
  запекалось в HTML при сборке — правки в разделе «PDF» доезжали только
  после пересборки всего сайта. В админке описание сохранялось, а страница
  его не показывала.
- **Лечение:** карточки на /catalogs теперь после загрузки страницы
  подтягивают живой `/api/pdfs` и подменяют описание (а заодно размер,
  дату и обложку) актуальными. Пока API не ответил — показываются
  запечённые значения, поэтому вид для поисковиков не пустеет.
- Проверено на статическом стенде: HTML собран БЕЗ описания, в браузере
  описание появилось сразу после открытия страницы — без пересборки.

## Технические детали

- `ChunkedUpload`: MAX_TOTAL 512 MB → **1024 MB**, максимум чанков 1000 →
  2000, диск-чек перед склейкой.
- `chunked-upload.ts`: бюджет 2000 чанков, текст ошибки «>1 GB».
- `CatalogsBrowser`: живой `usePdfDocs()` поверх запечённых карточек
  (гидратация без рассинхрона — первый рендер = SSR).
- Тесты `scripts/task111-tests.sh` — 12/12 (php -l, tsc, MAX_TOTAL,
  2500 чанков отклонены, 1500 чанков склеились, saveMeta → GET /api/pdfs
  отдаёт описание, в статике есть живой fetch). E2E вживую на статическом
  стенде (:8090): описание появилось в браузере без пересборки.
