# Лакомка — обновление v2026.11.14-0907 (Task 155)

Витрина: курсор-«палочка» (I-beam) больше не появляется над обычным текстом — только в полях ввода.

## Витрина и админка

- Раньше браузер показывал текстовый курсор над ЛЮБЫМ текстом (дефолтное `cursor: auto` над текстовым содержимым) — заголовки и абзацы выглядели как поля ввода, хотя ни один компонент этого не задавал.
- Теперь по умолчанию везде обычная стрелка (`body { cursor: default }`, наследуется всеми элементами).
- «Палочка» осталась только там, где она нужна: текстовые поля ввода, textarea (и contenteditable — на будущее). Поле количества на карточке товара, в корзине и в шторке — с настоящей «палочкой».
- Кнопки и ссылки по-прежнему показывают «руку» (pointer); у disabled-кнопок фирменные `disabled:cursor-*` не тронуты.
- Выделение текста мышью работает как раньше — изменился только вид курсора.

- Новые тесты: юнит 13/13 (маркеры CSS: три правила блока Task 155, contenteditable покрыт, нет грубого `* { … }`, cursor:text в файле один); e2e 7/7 computed-style на стенде :8096 — body/заголовок/абзац → `default`, ссылка/кнопка → `pointer`, поле количества на карточке товара → `text`.
