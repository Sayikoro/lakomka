# Лакомка — обновление v2026.11.04-1412 (Task 141)

Витрина: кнопка «Поделиться» в товаре, счётчик «До Нового года» на главной, быстрый просмотр из каталога. У категорий появились свои страницы с SEO.

## Витрина

- **Кнопка «Поделиться»** в карточке товара, под кнопкой «В корзину». На телефоне открывает системное меню шаринга, на компьютере — меню Telegram / WhatsApp / ВКонтакте и «Скопировать ссылку». Нажатия видны в аналитике (новое событие «поделился» с каналом).
- **Счётчик «До Нового года: N дней»** — синяя полоска сразу под главным экраном на главной: «До Нового года осталось 58 дней» + подпись «Успейте заказать — доставим к празднику». Число обновляется само; после Нового года просто снимите галочку (см. настройки).
- **Быстрый просмотр** — «глазок» на карточках каталога (на телефоне виден всегда, на компьютере — при наведении). Открывает компактную модалку: фото, цена, количество, «В корзину» и ссылка на полную карточку — не уходя со страницы. Открытие считается просмотром подарка, конверсия в аналитике не искажается.
- **Страницы категорий** — у каждой категории теперь свой адрес /catalog/<категория> (например, /catalog/vip): заголовок, описание и текст берутся из админки (пустые — автогенерация), плитки на главной и sitemap ведут на эти страницы.

## Админка

- **Настройки → Витрина** — две новые галочки: «Счётчик „До Нового года“ на главной» и «Быстрый просмотр товара в каталоге». Обе работают без пересборки сайта — сняли галочку, обновили страницу, фича исчезла.
- **Товары → «SEO категорий»** — для каждой категории: meta title, meta description и текст на странице категории (до 5000 символов). Сохранения пишутся в журнал действий.
- В разделе «Текст на страницах» появились новые строки: надпись и подпись счётчика ({days} — число, {days_word} — «день/дня/дней»), «Поделиться», «Быстрый просмотр», «Открыть карточку товара».
