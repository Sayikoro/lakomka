# Деплой-архив: как собрать lakomka-deploy-static.zip из частей

GitHub не принимает файлы больше 100 МБ, поэтому архив
`lakomka-deploy-static.zip` (117371644 байт) лежит в репозитории двумя частями:

| Файл | Размер |
| --- | --- |
| `lakomka-deploy-static.zip.part-00` | 94371840 байт |
| `lakomka-deploy-static.zip.part-01` | 23002804 байт |

## Склейка

Скачайте обе части в одну папку и выполните:

**Windows (cmd):**

```
copy /b lakomka-deploy-static.zip.part-00+lakomka-deploy-static.zip.part-01 lakomka-deploy-static.zip
```

**Linux / macOS:**

```
cat lakomka-deploy-static.zip.part-00 lakomka-deploy-static.zip.part-01 > lakomka-deploy-static.zip
```

# Медиа-синк: lakomka-media-2026.11.01-0754.zip

Медиа-архив 0105 НЕ выпускался: медиа не менялось — актуален
`lakomka-media-2026.11.01-0754.zip`.

Архив `lakomka-media-2026.11.01-0754.zip` (98386023 байт, 450 файлов,
все картинки товаров уже в WebP) лежит в репозитории ЦЕЛИКОМ
(`release/lakomka-media-2026.11.01-0754.zip`).

Это **МЕДИА-АРХИВ**: внутри только `uploads/**` (картинки и видео товаров)
и манифест `media_sync`. Он дозаливает на сервер всё медиа, которого там
не хватает — канал обычных обновлений возит статику БЕЗ медиа, поэтому
картинки, добавленные после первого деплоя, на сервере отсутствовали
(сотни 404, битые фото товаров).

## Как применить

1. Скачайте `lakomka-media-2026.11.01-0754.zip`.
2. Откройте сайт → `/update` (или админка → Настройки → «Обновление»).
3. Выберите файл и нажмите «Обновить сайт» — подтвердите «Применить
   МЕДИА-архив». Загрузка идёт по частям (98 МБ ≈ 200 чанков), затем
   распаковка прямо на сервере.
4. В статусе появится строка «Последний медиа-синк» с числом досланных файлов.

Страницы, скрипты и база данных (заказы, товары, настройки) не затрагиваются.

sha256:

```
f85fd27eabedcd048e0cf55ab667a0abc33cb239b691ccb90729b906b67347b6
```

## Когда медиа-синк нужен снова

После добавления в песочнице товаров с новыми фото/видео:
`MODE=media bash scripts/build-static.sh` (из готового `.deploy-package`)
→ свежий `lakomka-media-<версия>.zip` → применить тем же способом.

# Резервная копия из админки (с 2026.11.01-0621)

Снапшот текущего сайта теперь можно собрать прямо на сервере:
админка → Настройки → «Обновление» → карточка «Архив текущего сайта
(снапшот)» → «📦 Создать архив текущего сайта». Внутри — витрина,
backend, ВСЕ медиа и база данных; скачивание той же панелью загрузок.
Для переноса на другой хостинг: применить lakomka-deploy-static.zip
(свежий) и поверх — снапшот (распаковать в корень с заменой).

С 2026.11.02-0105 база дополнительно бэкапится АВТОМАТИЧЕСКИ:
раз в 3 суток (настраивается на вкладке «Здоровье») при первом
запросе к API снимок складывается в backend/storage/backups
(вне веб-корня), хранятся последние 10.
