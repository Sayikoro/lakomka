# Лакомка — обновление v2026.11.05-0109

## Счётчик «До Нового года» — в цвете сайта и в дизайне плиток условий

- **Блок больше не выделяется цветом**: синяя подложка убрана — блок лежит прямо на фоне страницы, как соседние секции.
- **Карточки отсчёта — в дизайне плиток условий** (СКИДКА / ДОСТАВКА / ОПЛАТА): белые, с тем же скруглением и мягкой тенью при наведении.
- **Цифры — фирменный синий**: тот самый синий сайта с лёгким свечением; надпись и подпись — в цветах сайта.
- **Гирлянда висит над карточками**: провод с огоньками теперь во всю ширину карточек, как будто огоньки растут из них; огоньки по-прежнему загораются по очереди при прокрутке.
- Плавные переходы сохранены: блок оживает при появлении на экране, карточки поднимаются одна за другой, секунды тикают как раньше.
- Всё остальное без изменений: галочка в настройках включает/выключает блок, тексты редактируются в админке.

## Как обновить

Админка → /update → «Проверить обновления (ГИТ)» → применить.
