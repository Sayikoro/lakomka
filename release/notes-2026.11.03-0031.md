# Лакомка — обновление v2026.11.03-0031

## Своя аналитика посещений (вкладка «Аналитика»)

- В админке появилась вкладка **«Аналитика»** — собственный сбор статистики витрины без внешних сервисов (Яндекс.Метрика продолжает работать параллельно, служебные визиты админки не считаются).
- **Сводка за период** (сегодня / 3 / 7 / 30 дней): сессии, люди и боты отдельно, просмотры страниц, просмотры подарков, добавления в корзину, клики.
- **Популярные подарки**: топ по открытиям карточек — обложка, название, сколько уникальных посетителей смотрело, сколько добавило в корзину, цена. Так видно, какие подарки интереснее всего.
- **Страницы витрины**: сколько просмотров у каждой страницы, средний доскролл (%) и среднее время на странице.
- **Откуда приходят**: источники заходов по доменам (Яндекс, Google, соцсети…) и прямые заходы.
- **Посетители**: каждая сессия — IP (замаскированный), User-Agent, источник, сколько страниц и событий, человек или бот. Кнопка **«🧭 Визит»** показывает весь визит по шагам: какие страницы открывал, куда нажимал, сколько доскроллил, какие подарки смотрел.
- **Боты и краулеры**: автоматизированные запросы к API (по User-Agent) — кто, с какого адреса, сколько запросов, какие маршруты.

## Защита от автоматизированных систем

- **Боты распознаются автоматически**: по User-Agent (50+ сигнатур — поисковые роботы, краулеры, скрипты) и по поведению (флуд страниц — 25+ страниц за 2 минуты помечается как бот, браузерный человек столько не открывает).
- **Кнопка «⛔ Блокировать»** — в списке ботов и в карточке любой сессии. Заблокированный адрес получает 403 на весь публичный API и на передачу аналитики. Разблокировка — одной кнопкой.
- **Лимиты запросов**: каталог и публичные API — не больше 120 запросов в минуту с одного адреса (и 3000 в час); **оформление заказов — не больше 5 в минуту и 30 в час с одного IP** (антиспам).
- **Приватность**: IP-адреса нигде не хранятся — только необратимый хеш с солью сайта (для блокировок) и маска вида `203.0.xxx.xxx` (для показа). Куки и персональные данные не собираются.
- События аналитики автоматически чистятся: события хранятся 90 дней, сессии — 180. Супер-админ может стереть всю аналитику кнопкой «Очистить аналитику» (блок-лист сохраняется).

## Прочее

- Просмотр аналитики доступен всем ролям админки; блокировка IP — редактору и супер-админу; очистка — только супер-админу.

*После применения: обновление ставится штатно (Настройки → «Обновление» или страница /update). Проверить: в админке слева появилась вкладка «Аналитика» — зайдите, откройте витрину в другом окне, походите по страницам и подаркам, через ~10 секунд нажмите «Обновить» в аналитике — визит появится в списке; в «Ботах и краулерах» уже сейчас видно поисковых роботов.*
