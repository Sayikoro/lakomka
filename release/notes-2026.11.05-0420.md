# Лакомка — обновление v2026.11.05-0420

## Галереи картинок из админки + шорткод [gallery …]

- **Новое: вкладка «Галерея» в разделе «Файлы»** — загрузка картинок для блоков сайта без FTP и разработчика: создайте галерею (например «Наши фабрики»), загрузите картинки, меняйте порядок стрелками, удаляйте лишнее.
- **Шорткод для любого блока**: у каждой галереи есть шорткод вида `[gallery fabriki]` — копируется кнопкой прямо из вкладки. Вставьте его в нужный блок — и на месте шорткода появится сетка картинок.
- **Блок «Конфеты от фабрик» теперь управляется галереей**: в Настройках появилось поле «Блок „Конфеты от фабрик“ — галерея логотипов». Уже работает галерея по умолчанию «Наши фабрики» с 18 логотипами — добавьте/замените логотип в «Файлы → Галерея», обновите страницу сайта (F5) — блок обновится **без пересборки сайта**.
- **SEO-текст категорий ожил**: текст категории (Товары → SEO категорий) теперь понимает шорткод `[gallery …]` и, главное, обновляется на сайте сразу после сохранения по F5 — раньше правки доживали до следующего обновления.
- Тяжёлые JPG/PNG при загрузке в галерею автоматически сжимаются в WebP.

## Как обновить

Админка → /update → «Проверить обновления (ГИТ)» → применить.
