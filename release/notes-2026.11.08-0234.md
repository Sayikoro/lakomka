# Лакомка — обновление v2026.11.08-0243 (Task 153: 12 улучшений админки)

Админ-часть: заказы стали инструментом, а не списком — фильтры, пагинация, деньги, выгрузка и печать; дашборд поднимает тревоги и показывает динамику; товары — категория и SEO прямо в форме; аналитика — произвольный период; безопасность — отзыв всех сессий.

## Заказы

- **Фильтры**: статус, номер заказа, телефон (точное совпадение — номер хранится зашифрованным), «письмо клиенту отправлено / не отправлено», период дат «с … по …». Плитки-тревоги с дашборда открывают список с уже подставленным фильтром.
- **Пагинация**: список больше не обрезается на 200 записях; переключатели страниц, выбор «на странице» 20/50/100/200; подвал с переключателем виден всегда.
- **Денежная сводка**: над списком «Найдено N заказ(ов) на сумму X ₽» — сумма считается по текущим фильтрам (сверяется с выгрузкой).
- **Экспорт CSV**: кнопка «Экспорт CSV» выгружает заказы по текущим фильтрам; файл открывается в Excel без танцев с кодировкой (BOM), статусы и доставка — человекочитаемым текстом.
- **Печать бланка**: в карточке заказа кнопка «Печать бланка» (Ctrl+P) — на бумаге только состав заказа, клиент и статус; меню и служебные панели скрыты.

## Дашборд («Обзор»)

- **Требует внимания**: красная плитка «Письма не ушли» (заказы, письмо клиенту по которым не отправилось из-за ошибки SMTP) и янтарная «Товары заканчиваются» (опубликованные товары с остатком ≤ 5, порог настраивается `low_stock_threshold`). Клик ведёт в готовый список.
- **Динамика за 14 дней**: график заказов (столбики) и визитов (линия) на чистом SVG, с легендой и подсказками по дням.

## Товары

- **Категория в форме товара**: выбирается при создании и редактировании (раньше — только массовая операция из списка).
- **SEO-поля**: «SEO-заголовок» и «SEO-описание» для поисковиков с подсказками длины; пустые — витрина берёт название/описание как раньше. Заполняются в `<title>`, description и Open Graph карточки товара.

## Аналитика

- **Произвольный период**: поля «с … по …» рядом с кнопками «Сегодня/3/7/30 дн.» — сводка, посетители, боты и график подчиняются диапазону; ✕ возвращает к кнопкам.
- **График по дням**: тот же, что на дашборде — заказы и визиты за выбранный период.

## Безопасность и гигиена

- **Выйти на всех устройствах**: новая кнопка рядом с «Выйти» в сайдбаре — все сессии аккаунта (телефон, планшет, другие браузеры) отзываются мгновенно, не дожидаясь 7-дневного срока токена.
- **Роль «Наблюдатель»**: из меню скрыты «Файлы» и «PDF» (внутри он и так получал отказ).
- **Тосты и подтверждения**: все браузерные confirm/alert заменены фирменными диалогами и уведомлениями (включая галереи из прошлого релиза).
- Статусы заказов сведены к единому источнику на фронте и бэкенде.
