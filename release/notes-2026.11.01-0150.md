# Релиз 2026.11.01-0150 (Task 107-109) — Метрика, Telegram, SEO-разметка

## Аналитика (Task 107)

- **Яндекс.Метрика одним полем.** Настройки → «Аналитика и уведомления» →
  номер счётчика (только цифры из metrika.yandex.ru). Счётчик вшивается
  во все страницы витрины (кликмап, переходы по ссылкам, точный отказ);
  официальная загрузка mc.yandex.ru, не тормозит первый рендер.
- **Админка без счётчика.** Метрика подключается только на витрине —
  служебные визиты в /admin не портят статистику.
- **Цели отправляются автоматически:** `add_to_cart` (любая кнопка
  «В корзину») и `order_created` (успешное оформление заказа, с номером
  заказа и суммой). Настраивайте их в Метрике как обычные JS-цели.
- Пустое поле = счётчика нет. Изменение применяется по F5, пересборка
  сайта не нужна. Ошиблись номером — витрина не падает.

## Telegram-уведомления о заказах (Task 108)

- **Мгновенное сообщение в ваш Telegram** при каждом заказе: номер,
  сумма, имя и телефон покупателя, способ доставки, адрес, комментарий
  и список товаров с количествами и ценами.
- Настройка: токен бота от @BotFather + chat_id (свой id — у
  @getmyid_bot; для группы/канала id отрицательный). Кнопка
  «Отправить тест в Telegram» проверяет настройки на месте.
- Токен хранится как секрет: в админке видна только маска «••••••••»,
  пустое поле = не менять; токен и chat_id не отдаются витрине.
- **Ошибка Telegram никогда не мешает заказу** — покупатель оформляет
  как обычно, ошибка доставки уходит в серверный лог; письма приходят
  как раньше.

## SEO и превью товара (Task 109)

- **Доступность по реальному остатку.** JSON-LD разметка и
  `product:availability` теперь честные: остаток 0 → `OutOfStock`
  (даже если товар виден в каталоге), есть остаток → `InStock`.
  Поисковики перестают показывать «в наличии» для разобранных позиций.
- **JSON-LD дополнен:** настоящее описание товара (короткая подстановка —
  только когда админ не заполнил описание) и `itemCondition: NewCondition`.
- **OG-картинка товара** (для превью в мессенджерах и соцсетях) — была
  и остаётся: первая фотография товара, цена в заголовке превью.
