# Прелоадер со смешными фразами — теперь виден при каждой загрузке (v2026.11.03-0424)

## Что сделано

**Зачем.** Прелоадер со смешными фразами показывался только при переходах между страницами
внутри сайта, да и то если переход длится дольше 150 мс. После ускорения витрины (прошлый
релиз) переходы стали такими быстрыми, что заставка практически исчезла, а при ПЕРВОМ
открытии сайта (по ссылке, из мессенджера, по F5) её не было никогда — посетитель смотрел
на белый экран, пока грузятся стили и скрипты. Отсюда «прелоадер на стороне пользователя
не появился».

**Как теперь.** Заставка со смешными фразами зашита прямо в HTML каждой страницы и
отрисовывается сразу при загрузке — раньше стилей и скриптов, даже на слабом интернете:
- случайная фраза из ~60 («Упаковываем конфеты в подарок…», «Отгоняем Деда Мороза от
  склада…») и ротация каждые 1,5 секунды;
- брендовое кольцо с подарком 🎁;
- заставка гасится, как только страница готова: обычно через ~1 секунду, на медленной
  сети — пока грузится (но не дольше 4 секунд — зависнуть не может);
- в админ-панели заставка не показывается — там её ничто не задерживает;
- если браузер совсем без JavaScript — заставка всё равно спрячется через 8 секунд
  (страховка на CSS);
- возврат «назад» в браузере — без застревшей заставки.

**Проверено автоматическими тестами:** 20 браузерных проверок на стенде — появление при
загрузке, ротация фраз, скрытие по таймингам, отсутствие в админке, поведение на
медленной сети (Slow 4G), отсутствие ошибок в консоли; плюс полный регресс всех прежних
задач (52+71+46+43+22+50+72+54+27+35+46+38+21+10 проверок) — всё зелёное.

## Применение
Настройки → «Обновление» (или страница /update) → «Проверить обновления (ГИТ)» → применить.
После обновления просто откройте сайт — заставка с фразой появится сразу.
