Лакомка v2026.10.30-0853 — живая витрина и видео без 503

ГЛАВНОЕ
1. Витрина теперь динамическая. Каталог, плитки категорий и карточки
   товаров стартуют с запечённых при сборке данных (быстрый первый
   рендер, SEO), затем сами подтягивают свежие данные с /api/products.
   Всё, что добавлено в админке НА СЕРВЕРЕ (товары, цены, фото, видео),
   появляется на витрине после обновления страницы (F5). Пересборка
   пакета больше не нужна для повседневной работы.
2. Товары, созданные ПОСЛЕ сборки пакета, открываются по прямой ссылке:
   если статической страницы нет, 404-страница сама находит товар в API
   и показывает полноценную карточку товара.
3. Видео товаров работает на витрине: превью при наведении (классическая
   карточка), слайды с видео и значок ▶ (новая карточка), видео в
   галерее на странице товара.
4. Исправлена ошибка 503 на видео (.mov/.mp4): в .htaccess добавлено
   явное правило — всё содержимое /uploads/ отдаётся Apache напрямую,
   мимо PHP (параллельные превью видео не выедают лимит процессов
   хостинга), плюс корректные MIME-типы (mov/mp4/webm/webp/avif) и
   кэширование видео на месяц.

УСТАНОВКА
- Штатно: /update → «Проверить обновления (ГИТ)» → «Скачать и установить».
  Медиа и база данных не затрагиваются.
- Полный деплой: архив из двух частей (README-RELEASE.md в репозитории).

ПРИМЕЧАНИЯ
- Если .htaccess на сайте редактировался вручную — обновление применит
  новую версию автоматически; сравните с версией из архива при желании.
- Честное ограничение: новые товары попадают в sitemap.xml и получают
  обычный 200-статус для поисковиков после очередной пересборки пакета.
- Галерея/файлы: «Видео» ищет по всем папкам /uploads, папку можно
  запомнить (v0715); attach принимает любые папки и имена файлов.
