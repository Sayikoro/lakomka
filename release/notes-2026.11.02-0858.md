# Лакомка — обновление v2026.11.02-0858

## Обложка и последняя страница для PDF-каталога

- В **Настройках появился блок «PDF по подаркам»**: загружаете две картинки — **обложку (первую страницу)** и **последнюю страницу** (например, заставку «Новогодние подарки» и страницу с контактами) — и жмёте «Сохранить».
- Дальше как обычно: **Товары → выделить подарки → «Сформировать PDF»** — документ собирается в порядке: обложка → карточки подарков (фото, название, цена) → финальная страница.
- Картинка обложки вписывается в лист А4 целиком, без обрезки (любые пропорции). Не заданы — PDF такой же, как раньше, сразу с карточек.
- Если файл обложки случайно удалён — PDF всё равно сформируется без этой страницы, ничего не ломается.

## Прочее

- Настройки обложек принимают только файлы, загруженные через админку (`/uploads/…`); внешние ссылки и пути с «..» отклоняются, страницы обложек не видны на витрине.
- Загруженные обложки автоматически сжимаются (как картинки hero).

*После применения: медиа-архив не требуется, все правки приедут обновлением. Проверить: Настройки → «PDF по подаркам» → загрузить обложку → Товары → выделить пару подарков → «Сформировать PDF».*
